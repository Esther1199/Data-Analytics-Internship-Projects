# Project 2: Data Analysis
## Project Overview
This project was completed as part of my Data Analytics Internship with Decode Labs.
Following the data cleaning process completed in Project 1, I performed Exploratory Data Analysis (EDA) on an ecommerce dataset containing 1,200 orders covering January 2023 to June 2025.
The objective was to explore was to explore the cleaned dataset, identify trends and patterns, examine distributions, and generate meaningful business insights.
## Tools Used
- Microsoft Excel
## Objectives
The analysis was conducted to:
- Understand the overall characteristics of the dataset
- Calculate descriptive statistics
- Analyze order performance over time
- Identify unique customers and products
- Examine product performance
- Analyze payment methods and referral sources
- Investigate order-status distribution
- Examine coupon usage
- Identify potential outliers
- Generate meaningful business insights
  ## Key Performance Indicators (KPIs)
  The analysis produced the following key metrics:
  - **Total Orders:** 1,200
  - **Total Order Value:** 1,264,762
  - **Average Order Value:** 1,054
  - **Unique Customers:** 1,189
  - **Unique Products:** 7
    ## Trends and Patterns
    The analysis revealed several trends and patterns within the dataset, including differences in sales performance across products and variations in customer purchasing behavior.
    Further analysis was used to identify the products, customers, and periods that contributed most significantly to overall sales performance.
    ## Key Findings
    ### Product Performance
    - **Printer** had the highest number or orders.
    - **Chair** generated the highest total order value.
    - **Laptop** had the highest average order value.
    - **Phone** had the lowest average order value.
      ### Referral Source Analysis
    - **Instagram** was the leading referral source, generating the highest number of orders and the highest total order value.
      ### Time-Based Analysis
    - Average order value showed a declining pattern across comparable January-June periods from 2023 to 2025.
      ### Distribution of Order Values
    - - The distribution of order values was right-skewed.
    - - The mean was higher than the median, indicating that some higher-value orders influenced the overall average.
      ### Outlier Analysis
    - - Using the Interquartile Range (IQR) method, I identified **8 potential high-value outliers** in the Total price variable.
    - - These values were investigated rather than automatically treated as errors.
      ## Business insights
      The analysis provides several insights that could support business decision-making.
      The strong performance of Printer by order volume and Chair by total order value suggests that performance should be evaluated using multiple metrics rather than relying on order count alone.
      Instagram's strong performance as a referral source suggests that it may be an important channel for customer acquisition and could warrant further investigation.
      The declining average order value across comparable January-June periods may indicate a change in purchasing behavior and would be worth monitoring.
      The presence of high-value outliers also demonstrates the importance of investigating unusual transactions before deciding whether they represent errors or legitimate business activity.
       ## What I Learned
      This project strengthened my understanding of Exploratory Data Analysis and demonstrated that data analysis goes beyond calculating numbers.
      I learned the importance of asking questions about the patterns in the data, investigating what may be causing those patterns, and considering what the finding mean from a business perspective.
      The project also provided hands-on experience with Excel formulas, descriptive statistics, exploratory data analysis, outlier detection, and data storytelling.
      ## Conclusion
      The analysis transformed the cleaned dataset into meaningful insights about customer behavior, product performance, referral sources, order values, and sales trends.
      This project demonstrated how Excel can be used to explore business data and support data-driven decision-making.
