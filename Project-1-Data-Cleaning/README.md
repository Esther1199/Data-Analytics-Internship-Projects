# Project 1: Data Cleaning
## Project Overview
This project was completed as part of my Data Analytics Internship at Decode Lab.
The objective of this project was to clean and prepare a raw dataset for further analysis and visualization.
## Data Cleaning Tasks
- Removed duplicate records
- Handled blank and missing values
- Corrected inconsistent formatting
- Standardized data entries
- Checked and corrected data inconsistencies
- Prepared the dataset for analysis
  ## Tools Used
  -Microsoft Excel
  -Power Query
  ## Project Outcome
  The raw dataset was transformed into a cleaner, more structured, and analysis-ready dataset.
  ## Key Learning
  This project strengthened my understanding of data cleaning, data quality, consistency, and the importance of preparing data before performing analysis.
